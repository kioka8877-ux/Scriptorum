### SOURCE 2 : TikTok (Volumétrie de hashtags & Engagements)
**Méthode :** Scraping via `TikTokApi` (Python) en mode headless (utilisation de requêtes HTTP directes via Playwright stealth ou bypass de signature). *Note : En CI sans navigateur, le plus stable est l'API non officielle de scraping de hashtags.*
**Dépendance CI :** `pip install TikTokApi playwright` + `playwright install chromium --with-deps`

**Code Python exact pour CI (Headless) :**
```python
import asyncio
from TikTokApi import TikTokApi

async def get_tiktok_virality(hashtag_name):
    # En CI, on force un user-agent mobile pour éviter les captchas
    async with TikTokApi() as api:
        await api.create_sessions(num_sessions=1, sleep_after=3, headless=True, browser_args=["--no-sandbox", "--disable-gpu"])
        tag = api.hashtag(name=hashtag_name)
        # Récupère les 10 vidéos les plus récentes/populaires du hashtag
        videos = []
        async for video in tag.videos(count=10):
            info = await video.info()
            videos.append({
                'views': info.get('stats', {}).get('playCount', 0),
                'likes': info.get('stats', {}).get('diggCount', 0),
                'shares': info.get('stats', {}).get('shareCount', 0)
            })
        
        total_views = sum(v['views'] for v in videos)
        total_shares = sum(v['shares'] for v in videos)
        
        # Indicateur de viralité TikTok : Ratio de Share (Partages) > 5% des vues
        share_rate = (total_shares / total_views) * 100 if total_views > 0 else 0
        
        return {
            "hashtag": hashtag_name,
            "total_views_sample": total_views,
            "share_rate": share_rate,
            "is_viral": share_rate > 5.0 # Seuil arbitraire validé en forge
        }
```

### SOURCE 3 : Google Trends (Tendance de recherche temporelle)
**Méthode :** Utilisation de `pytrends` (API non officielle de Google Trends). Ne nécessite aucune clé, fonctionne par requêtes HTTP pures.
**Dépendance CI :** `pip install pytrends pandas`

**Code Python exact pour CI :**
```python
from pytrends.request import TrendReq
import pandas as pd
import time

def check_google_trend(keyword):
    # Délai anti-rate-limit pour le CI
    time.sleep(2)
    pytrends = TrendReq(hl='fr-FR', tz=360, timeout=(10, 25), retries=2, backoff_factor=0.5)
    
    # Période : 7 derniers jours pour capter l'explosion immédiate
    pytrends.build_payload([keyword], cat=0, timeframe='now 7-d', geo='', gprop='')
    
    df = pytrends.interest_over_time()
    
    if df.empty or keyword not in df.columns:
        return {"keyword": keyword, "is_trending": False, "reason": "No data"}
        
    # Récupérer les valeurs du premier jour vs dernier jour
    start_val = df[keyword].iloc[0]
    end_val = df[keyword].iloc[-1]
    
    # Calcul du multiplicateur de croissance
    if start_val > 0:
        growth_multiplier = end_val / start_val
    else:
        growth_multiplier = end_val if end_val > 0 else 0
        
    is_trending = growth_multiplier >= 2.0 # A doublé en 7 jours
    
    return {
        "keyword": keyword,
        "start_interest": int(start_val),
        "end_interest": int(end_val),
        "growth_multiplier": float(growth_multiplier),
        "is_trending": is_trending
    }
```
